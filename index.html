    COME FUNZIONA IL CASO

    FILE & ORDER manda file da un dispositivo all'altro senza conservarli su nessun server. È scritto in HTML, CSS e JavaScript e usa la tecnologia peer-to-peer (P2P) dei browser.

    1. Scegli uno o più file: il sito li impacchetta in un unico ZIP.
    2. Compaiono un ID e un QR code: sono la chiave del caso.
    3. L'altro dispositivo inserisce l'ID o inquadra il QR.
    4. Il mittente autorizza la richiesta e il destinatario accetta il file.
    5. Lo ZIP viaggia a pezzetti, direttamente da dispositivo a dispositivo.
    6. All'arrivo il sito verifica che nulla sia stato alterato e fa passare l'antivirus.
    WebRTC
    Tecnologia dei browser che permette a due dispositivi di parlarsi direttamente, come due agenti con una linea riservata.
    Centralino
    Per presentarsi, i due dispositivi passano da un piccolo server di segnalazione (PeerJS). Scambia solo i dati per stabilire il collegamento: i file non lo attraversano mai.
    Canale cifrato
    Una volta collegati, i dati viaggiano in un canale cifrato (DTLS): chi sta in mezzo non può leggerli.
    Blocchi
    Lo ZIP è spezzato in blocchi piccoli con controllo del flusso, così la connessione non si intasa e il sito può mostrare velocità e tempo stimato.
    Integrità
    Prima dell'invio si calcola l'impronta digitale (SHA-256) dello ZIP; all'arrivo la si ricalcola e la si confronta. Se non coincide, il file viene scartato.
    Limiti e RAM
    Il limite è 2 GB, ma tutto passa dalla memoria RAM: per comprimere e inviare serve circa il doppio del peso, e chi riceve ne tiene una copia intera. Con file grossi usa un PC e chiudi le altre schede. In reti molto restrittive il collegamento diretto può non riuscire.

    L'ANTIVIRUS DEL DETECTIVE

    Prima che un file parta, e di nuovo quando arriva, un detective digitale lo ispeziona. Lavora solo sul tuo dispositivo: nessun file viene caricato altrove per essere controllato.

    NOME
    Osserva nome ed estensione, alla ricerca di travestimenti.
    STRUTTURA
    Confronta ciò che il file dichiara di essere con ciò che è davvero.
    CONTENUTO
    Cerca comportamenti tipici dei software dannosi.
    ARCHIVIO
    Controlla anche dentro lo ZIP, file per file.

    Ogni file riceve un verdetto:

    OKNOTASOSPETTOPERICOLO

    Se trova un criminale, un allarme spiega che cosa ha trovato e in quale file; per proseguire servono due conferme consapevoli.

    Limiti onesti. È un controllo euristico: può sbagliare in entrambi i sensi e non sostituisce un antivirus completo. Sui file molto grandi analizza solo alcune parti. I dettagli tecnici restano riservati, come in ogni buon fascicolo.
